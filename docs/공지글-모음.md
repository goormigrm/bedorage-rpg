# 공지글 모음

공개 때 게시판·카페에 붙여 넣을 **게임 소개 글**이다. (2026-09-24 — klo26 `docs/공지글-모음.md` 형식 · 같은 날 발표 자료처럼 짧게 · 이야기 뺌)

## 쓰는 법

> **기준은 1차 공지 본문** — 2026-10-06 사용자가 직접 다시 쓴 글이다. 새 글도 그만큼 짧게 쓴다
> (사용자: "앞으로도 이런 식으로 불필요한 말은 삭제하고 작성해").

- **핵심만.** 묶음마다 항목 두세 줄 ~ 많아야 다섯 줄. 읽는 사람이 게임을 고르는 데 필요 없는 것은 뺀다 —
  조작 · 설정 · 운영 세부(길 안내 · 업적 · 통계 · 보관함 늘리기 · 방장 내보내기 · 소리 크기 · 자동 화질 · 방송인 조절 · 폰 안내 같은 것)는 넣지 않는다.
- 한 항목도 짧게 — 설명을 덧붙이지 않는다("최대 체력 % 피해 — 탱커도 똑같이 · 상태 이상 면역" → "최대 체력 % 피해", "가끔 즉사기 — 보스 대사 · …" → "가끔 즉사기").
- 맨 위는 게임 이름 → **주소** → 한 줄 소개 → "설치 없음 · 가입 없음". 주소는 맨 아래에도 한 번 더.
- 큰 제목에만 이모지, 그 아래 한 줄(부제), 항목은 `*`. 묶음 사이는 빈 줄 하나 · 부제 바로 아래부터 항목.
- 서술형("~입니다") 금지 — 명사 · 짧은 구로 끝낸다.
- **이야기(줄거리)는 쓰지 않는다** — 스포일러. "계란이 된 크루" 처럼 화면에 보이는 것까지만.
- **"고쳤다"가 아니라 "이 게임은 이렇다"로** 쓴다. 개발 용어(파일명 · 상수 · 수치 근거)는 넣지 않는다.
- 마크다운 굵게 금지 — 게시판 편집기가 모른다. 문안은 코드 블록 안에 — 줄바꿈이 그대로 복사된다.
- 다른 회사 · 게임 이름은 안 쓴다(치지직은 예외 — 연동 기능 이름). '디아블로식' 같은 비유도 쓰지 않는다.
- 캐릭터는 모두 ○○란(계란)이다. '덕' · '오리' 라는 말은 쓰지 않는다.
- 숫자 · 키를 고칠 때는 맨 아래 확인 표를 본다. 처음 하는 사람에게는 [플레이 가이드](플레이-가이드.md)를 같이 보낸다.
