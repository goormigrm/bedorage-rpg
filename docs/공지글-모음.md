# 공지글 모음

공개 때 게시판·카페에 붙여 넣을 **게임 소개 글**이다. (2026-09-24 — klo26 `docs/공지글-모음.md` 형식으로 다시 썼다)

## 쓰는 법

- **한 줄에 한 가지.** 짧게 끊고 늘이지 않는다.
- 큰 제목에만 이모지, 그 아래 한 줄, 항목은 `*`.
- **"고쳤다"가 아니라 "이 게임은 이렇게 돌아간다"로** 쓴다.
- 개발 용어(파일명·상수·수치 근거)는 넣지 않는다.
- 마크다운 굵게 금지 — 게시판 편집기가 모른다.
- 문안은 코드 블록 안에 — 줄바꿈이 그대로 복사된다.
- 다른 회사·게임 이름은 안 쓴다 (치지직은 예외 — 연동 기능 이름). '디아블로식' 같은 비유도 쓰지 않는다.
- 캐릭터는 모두 ○○란(계란)이다. '덕' · '오리' 라는 말은 쓰지 않는다.
- 숫자·키를 고칠 때는 맨 아래 확인 표를 본다.
- 처음 하는 사람에게는 [플레이 가이드](플레이-가이드.md)를 같이 보낸다.

## 0. 첨부

> 파일은 로컬 `docs/img/` 에만 있다(저장소에 안 넣는다). 다시 뜨는 절차는 HANDOVER "공지 사진 다시 뜨기" · `tools/trailer.js` 머리 주석.
> 게시판 규칙: 글 하나에 총 50 MB · 영상 12개까지, 파일당 40 MB. 아래 넷이면 약 36 MB.
> 게임 소개는 영상 한 편 + 메인 사진 셋으로 한다 (2026-09-23 사용자).

| 파일 | 크기 | 캡션 |
|---|---|---|
| `trailer.webm` | 약 35 MB | 1분 — 소개 영상 (소리 · 자막) |
| `shot_town.jpg` | 0.2 MB | 눈을 뜨면 순례자 야영지입니다 |
| `shot_fight.jpg` | 0.2 MB | 잠든 무리가 총소리에 깨어 몰려옵니다 |
| `shot_boss.jpg` | 0.3 MB | 붉은 범위가 다 차오르기 전에 빠져나가세요 |

영상 흐름: 제목 → 야영지 → 몰려드는 괴물 떼 → 스킬 · 궁극기 → 치지직(괴물 말풍선 · 응원 · 후원으로 막 보스) → 도살자 패턴 → 심연의 군주 → 전리품 → 끝 카드.

남는 것: `gif_queen_boss` 거미 여왕 · `gif_rapier_wolves` 늑대 떼 · `gif_violin_horde` 고기 바이올린 — 댓글 · 단톡용.

## 1차 — 오픈 베타 공지

제목

```
배도라지RPG — 계란이 된 배도라지 크루 12명의 쿼터뷰 슈팅 RPG (PC 브라우저, 최대 4인, 무료)
```

본문

```
배도라지RPG 오픈 베타
MT 에서 공포체험을 하다 길을 잃은 배도라지 크루가 낯선 야영지에서 눈을 뜹니다.
마을에서 시작해 이어진 세계를 걸어 내려가는 쿼터뷰 슈팅 RPG입니다.
PC 브라우저에서 주소만 열면 됩니다. 설치도 가입도 없습니다.

🥚 이야기
정신을 차려 보니 모두 계란이 되어 있었습니다.

* MT 밤, 산속의 버려진 성당으로 공포체험을 갔습니다
* 종소리가 한 번 울리고 돌아 나갈 길이 사라졌습니다
* 다 같이 정신을 잃었다가 순례자 야영지에서 깨어납니다
* 껍데기가 깨지기 전에 돌아가려면 멈춘 종을 다시 울려야 합니다
* 종은 셋으로 흩어져 막 보스들이 쥐고 있습니다

⛪ 세계
방을 옮겨 다니지 않고 걸어서 이어집니다.

* 4막 · 36지역 · 막 보스 넷입니다
* 마을 → 들판 → 던전 → 보스 방 순서로 내려갑니다
* 막마다 촌장이 퀘스트 넷을 맡깁니다
* 막 보스를 잡으면 그 자리에 다음 막 문이 열립니다
* 웨이포인트와 타운 포털로 오갑니다
* 보통 난이도 한 바퀴는 5~6시간 안팎입니다
* 다 깨면 악몽, 그다음 지옥 난이도가 열립니다

🎯 막 보스
외우고 피해야 이깁니다.

* 보스마다 패턴 셋 이상을 정해진 차례로 씁니다
* 빨간 범위가 차오르면 터집니다 — 원, 고리, 줄, 부채 모양입니다
* 보스 공격은 최대 체력의 % 라 탱커도 똑같이 아픕니다
* 보스에게는 기절, 둔화, 넉백, 도발이 먹히지 않습니다
* 체력이 줄면 분노해 패턴이 늘어납니다
* 보스 방은 벽도 상자도 없는 둥근 결투장입니다
* 체력이 10% 줄 때마다 회복 구슬이 떨어집니다

👹 괴물
모든 괴물과 보스가 실사 모델입니다.

* 잠든 무리는 총소리에 깨어 몰려옵니다
* 정예는 빠름, 단단함, 폭발, 분열, 흡혈 같은 접두 능력이 붙습니다
* 공격 전에 예고가 있고, 구르면 맞지 않습니다
* 느린 PC 는 Esc 메뉴에서 실사 괴물을 끌 수 있습니다

⚡ 캐릭터 12명
탱커 셋, 딜러 여섯, 힐러 셋입니다.

* 철면란 — 탱커, 고기 바이올린
* 승빠란 — 탱커, 총알을 튕기는 후라이팬
* 풍월란 — 탱커, 산탄총, 맞을수록 단단해집니다
* 침착란 — 딜러, 소총
* 단군란 — 딜러, 무리를 깨우지 않는 소음기 SMG
* 옥냥란 — 딜러, 저격총
* 우원란 — 딜러, 소음기 SMG, 구른 뒤 무적
* 기열란 — 딜러, 소총, 맞힐수록 아파집니다
* 우재란 — 딜러, 길고 얇은 검
* 매직란 — 힐러, 산탄총
* 주펄란 — 힐러, SMG
* 통천란 — 힐러, 저격총
* 모두 스킬 둘과 궁극기, 스킬 트리로 두 가지 빌드가 나옵니다

🔫 전투
재장전이 없습니다.

* 꾹 누르면 끝없이 쏩니다
* 조준선이 금색일 때 맞히면 약점 치명타입니다
* 회복은 괴물이 떨어뜨리는 체력 구슬로 합니다

💰 전리품
사람마다 따로 떨어집니다.

* 마법, 희귀, 전설, 신화 등급이 있습니다
* 전설에는 고유 효과가 붙습니다
* 계열마다 변형 무기가 있습니다
* 대장장이에서 강화하고, 모아서 벼립니다
* 상인, 도박꾼, 보관함, 용병이 마을에 있습니다

👥 같이 하기
혼자도 되고 최대 4명입니다.

* 게임을 만들면 목록에 바로 뜨고, 친구는 참가만 누르면 됩니다
* 빈 자리는 봇으로 채울 수 있습니다
* 게임 중에도 남은 자리로 들어올 수 있습니다
* 서로 다른 지역에 있어도 됩니다
* 누르고 말하는 음성 대화가 있습니다
* 투기장에서는 키운 캐릭터끼리 겨룹니다
* 괴물 체력은 방 인원에 맞춰 늘어납니다 — 혼자 하는 건 도전입니다

📺 치지직 방송
방송하는 분을 위한 기능입니다.

* 시청자 채팅이 괴물 머리 위 말풍선으로 뜹니다
* 후원 금액에 따라 좀비 떼, 암흑, 중간보스, 막 보스 같은 이벤트가 일어납니다
* 후원 글에 !응원 을 쓰면 괴롭히는 대신 우리 편을 돕습니다
* 금액표는 방송인이 정하고, 받은 개수와 합계는 어디에도 보이지 않습니다

🌐 온라인
서버가 없습니다.

* 브라우저끼리 직접 연결됩니다
* 그래서 무료이고, 그래서 가끔 연결이 안 됩니다
* 안 되면 한 명이 폰 핫스팟으로 바꿔 보세요

🆓 무료
광고도 결제도 계정도 없습니다.

* 캐릭터는 여러분 브라우저에만 저장됩니다
* 다른 PC 로는 세이브 내보내기, 가져오기로 옮깁니다
* 폰은 참가만 됩니다 — 방은 PC 에서 만드세요
* 비공식 팬 프로젝트입니다. 문제가 되면 바로 내립니다

🔗 https://goormigrm.github.io/bedorage-rpg/

이상한 점은 댓글로 알려 주세요. "이 보스 너무 세다, 약하다" 가 제일 큰 도움이 됩니다.
```
