# 공지글 모음

공개 때 게시판·카페에 붙여 넣을 **게임 소개 글**이다. (2026-09-24 — klo26 `docs/공지글-모음.md` 형식 · 같은 날 발표 자료처럼 짧게 · 이야기 뺌)

## 쓰는 법

- **발표 자료처럼.** 한 줄에 한 가지, 핵심만 — 서술형 문장("~입니다")으로 늘이지 않고 명사 · 짧은 구로 끝낸다 (2026-09-24 사용자: "서술형이 아니라 PPT 발표처럼 주요한 내용만 간결하게").
- **이야기(줄거리)는 쓰지 않는다** — 스포일러 (2026-09-24 사용자). "계란이 된 크루" 처럼 화면에 보이는 것까지만.
- 큰 제목에만 이모지, 그 아래 한 줄(부제), 항목은 `*`. 묶음마다 항목은 대여섯 줄 안.
- **"고쳤다"가 아니라 "이 게임은 이렇다"로** 쓴다.
- 개발 용어(파일명·상수·수치 근거)는 넣지 않는다.
- 마크다운 굵게 금지 — 게시판 편집기가 모른다.
- 문안은 코드 블록 안에 — 줄바꿈이 그대로 복사된다.
- 다른 회사·게임 이름은 안 쓴다 (치지직은 예외 — 연동 기능 이름). '디아블로식' 같은 비유도 쓰지 않는다.
- 캐릭터는 모두 ○○란(계란)이다. '덕' · '오리' 라는 말은 쓰지 않는다.
- 숫자·키를 고칠 때는 맨 아래 확인 표를 본다.
- 처음 하는 사람에게는 [플레이 가이드](플레이-가이드.md)를 같이 보낸다.

## 0. 첨부

> 파일은 로컬 `docs/img/` 에만 있다(저장소에 안 넣는다). 다시 뜨는 절차는 HANDOVER "공지 사진 다시 뜨기" · `tools/trailer.js` 머리 주석.
> 게시판 규칙: 글 하나에 총 50 MB · 영상 12개까지, 파일당 40 MB. 영상은 늘 두 벌(2026-09-24 사용자): 게시판용 `trailer.webm`(38 MB 안 — 뜬 뒤 크기로 고른다) · 고화질 `trailer_hq.webm`.
> 게임 소개는 영상 한 편 + 메인 사진 셋으로 한다 (2026-09-23 사용자).

| 파일 | 크기 | 캡션 |
|---|---|---|
| `trailer.webm` | 34.2 MB | 1분 57초 소개 영상 — **게시판용** 720 · 2.2 Mbps · 소리 · 자막 · 주인공 철면란 |
| `trailer_hq.webm` | 217 MB | 같은 영상 **고화질** 1080 · 16 Mbps — 영상 사이트 · 드라이브용 (게시판에는 못 올린다) |
| `shot_town.jpg` | 0.2 MB | 마을 — 순례자 야영지 |

영상 흐름: 캐릭터 고르는 화면(제목 "배도라지 알PG" · 침착란 · 단군란 · 매직란 · 철면란이 불 앞으로) → 마을 → 괴물 떼 → 스킬 외침 · 궁극기 → 정예 → 치지직 34초(왼쪽에 후원 표 · 괴물 말풍선 · 링크 가림 · !참여 시청자 이름 괴물 등장 · 처치 → 금액마다 이벤트 좀비 떼 둘 · 정예 무리 · 이름표 → 큰 후원 3초 예고 → 중간보스 → "○○님의 중간보스 처치!" → !응원 아군 괴물 넷 · 아군 보스 → 스킬 봉인 예고 · HUD 봉인 — 괴물 내내 50 넘게) → 거대한 보스 방 넷(보통 패턴 + 보스마다 대사 한마디 — 즉사기는 스포일러라 뺐다) → 크루 12명이 함께 심연의 군주 → 전리품 → 끝 카드(싸움 위). 장면마다 검게 닫았다 여는 전환.

이름: **배도라지 알PG** — 제목 글자에서 '알'은 노른자 빛(게임 로비 · 영상과 같게). 게시판 제목에 색을 못 넣으면 글자만.
