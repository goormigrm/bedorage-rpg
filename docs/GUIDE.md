## 1. 왜 다시 썼나

사용자(2026-09-18): **"난 디아블로 같은 게임을 원했는데 전혀 다른 게임이 되어 가고 있어."**

v0.7.0 까지의 빌드는 "배도라지 덕(대전 슈터)에 몬스터와 레벨을 얹은 **스테이지 클리어형 슈터**" 였다. 사용자가 짚은 곳은 셋:

| 사용자가 짚은 곳 | 디아블로 | v0.7.0 (틀린 것) |
|---|---|---|
| **게임 흐름 · 세계 구조** | 캐릭터 선택 → **마을에서 시작** → NPC·퀘스트 → 걸어서 야외 → 던전 → 보스 → 다음 막. 웨이포인트·타운 포털. 세계가 이어져 있고 결과 화면이 없다 | 로비에서 원정 고르기 → 카운트다운 "시작!" → 3층 → **결과표(처치·명중률)** → "다음 원정" 버튼. 마을은 메뉴 |

**원인(내 판단 착오)**: PLAN 2장에서 "서버가 없으니 세계를 켜 둘 곳이 없다 → 20~30분 원정 단위" 로 정했다. 그러나 **디아블로 2 가 원래 그렇다** — 방을 만들 때마다 세계가 새로 생기고, 남는 것은 캐릭터(레벨·아이템·퀘스트·웨이포인트)뿐이다. 서버 없는 P2P 에 디아블로 2 의 구조가 그대로 들어맞는다. 구조를 바꿀 이유가 없었다.

전투 감각은 사용자가 문제 삼지 않았다 → **총 슈팅은 유지하고 스킬 비중을 키운다**(7장).

## 2. 기준 — "디아블로 같다" 의 정의

새 기능·화면을 만들 때마다 아래 일곱 기둥에 비춰 본다. 하나라도 어기면 방향이 틀린 것이다.

1. **마을에서 시작해 마을로 돌아온다.** 마을은 걸어 다니는 장소다(메뉴가 아니다). 상인·대장장이·보관함·퀘스트 NPC·웨이포인트가 있다.
2. **세계는 이어져 있다.** 다음 곳은 걸어서(출구·계단·동굴 입구), 빠른 이동은 웨이포인트와 타운 포털로. 스테이지 선택 메뉴·카운트다운·결과 화면은 없다.
3. **퀘스트가 길을 이끈다.** 막마다 퀘스트 서너 개, 끝은 막 보스. NPC 가 말을 걸고, 퀘스트 기록이 있다.
4. **전리품이 쏟아진다.** 몬스터·상자·항아리에서 골드 더미·물약·아이템이 바닥에 떨어지고(이름표), 주워서 끼거나 판다. 정예·보스는 전리품 분수.
5. **성장에 선택이 있다.** 레벨업 = 스킬 포인트. 어떤 스킬을 키울지, 어떤 전설 효과로 빌드를 짤지.
6. **무리를 쓸어 담는다.** 몬스터는 떼로 오고, 정예 무리·우두머리·보스가 고비다. 스킬이 전투의 절반 이상.
7. **어둡고 고딕하다.** 빛 반경 · 횃불 · 폐허 · 시체 · 돌과 쇠의 UI · 명조체. 어느 화면에서도 덕(밝은 대전 게임)의 흔적이 보이면 안 된다.

**어느 디아블로를 따르나** (섞되, 항목마다 하나를 정본으로):

| 영역 | 정본 | 내용 |
|---|---|---|
| 세계·진행 구조 | **디아블로 2** | 막 · 막마다 마을 · 야외 → 던전 · 웨이포인트 · 타운 포털 · 퀘스트 · 난이도 3단계(보통/악몽/지옥) · 방을 만들 때마다 세계가 새로 생김 · 용병 |
| 화면·UI·편의 | **디아블로 4** | 체력/자원 구슬 · 스킬 바 · 가방·툴팁 · 물약 충전식 · 감정 없음 · 능력치 직접 분배 없음 · 스킬 트리(포인트) · 구르기(회피) · WASD 지원 |

## 4. 게임 흐름 (목표)

```
타이틀 → 캐릭터 선택(모닥불 앞에 선 캐릭터들 · 이름 · 레벨 · 진행한 막)
   └ [게임 만들기] [게임 참가(목록)] [혼자 하기] [투기장]
        └ 게임에 들어가면 = 그 막의 **마을에 서 있다** (카운트다운 없음)
             ├ NPC: 퀘스트 · 상인 · 대장장이 · 도박꾼 · 보관함 · 용병 대장
             ├ 성문 밖 → 야외 지역 → (동굴·묘지 입구) → 던전 1~3층 → … → 막 보스
             ├ 웨이포인트(밟아서 열기 → 마을↔지역 빠른 이동) · 타운 포털(T)
             ├ 죽으면 마을에서 다시 일어난다(벌칙은 방장 규칙)
             └ 막 보스를 잡고 NPC 에게 말하면 다음 막 마을로
   게임에서 나가기 = 캐릭터(레벨·아이템·스킬·퀘스트·웨이포인트)는 저장, 세계는 사라진다 (디아블로 2 와 같다)
```

- **한 게임(방)의 길이는 열려 있다.** 10분을 해도 3시간을 해도 된다. 결과 화면은 없다(투기장만 있다).
- 방장이 끊기면 그 게임은 끝나지만 모두의 캐릭터는 이미 저장돼 있다 → 새 게임을 만들어 웨이포인트로 돌아간다.
- 다 깬 뒤: 악몽 → 지옥 난이도(같은 세계, 지역 레벨↑, 정예 능력↑, 전리품 등급↑). 6시간은 **보통 난이도 한 바퀴** 기준.

## 5. 세계 구조

### 5.1 막 · 지역

- **막(Act) 4개.** 막마다 마을 1 + 야외 지역 2~3 + 던전 2~3(각 1~3층) + 보스 방. 한 막 약 9~10개 맵, 맵 하나 평균 7분 → 막당 약 80분 + 마을·보스·죽음 ≈ **6시간**.
- 지역은 `src/core/world.ts` 의 표 하나로 정의한다: 이름 · 막 · 종류(마을/야외/던전/보스 방) · 맵 생성기와 테마 · 지역 레벨 · 무리 틀 · **출구 목록(어느 지역의 어느 입구로 이어지나)** · 웨이포인트 유무 · 걸린 퀘스트.
- 지역 레벨은 고정(디아블로 2). 난이도가 오르면 통째로 올라간다. 아이템 레벨 = 지역 레벨.
- 맵은 (게임 시드, 지역 번호)로 만든다 → 모든 브라우저가 같은 세계, 게임을 새로 만들면 다른 세계.

**1막 — 무너진 성당** (기준 설계. 2~4막은 같은 틀로)

| # | 지역 | 종류 · 생성기 | Lv | 내용 |
|---|---|---|---|---|
| 0 | 순례자 야영지 | 마을 (손으로 짠 배치) | — | 촌장(퀘스트) · 상인 · 대장장이 · 도박꾼 · 보관함 · 용병 대장 · 웨이포인트 · 모닥불 |
| 1 | 핏빛 들판 | 야외 (scatter) | 1 | 구울 떼. 동굴 입구 · 묘지 길로 가는 출구 |
| 2 | 굶주린 굴 | 던전 1층 (rooms) | 2 | **퀘스트 1 "굴 속의 것들"** — 굴을 비운다 → 스킬 포인트 |
| 3 | 묘지 길 ⚑ | 야외 | 3 | 우두머리 **묘지기 오스** — **퀘스트 2** → 상인 할인. 웨이포인트 |
| 4·5 | 지하 묘지 1·2층 | 던전 | 4·5 | 해골 궁수 · 부푼 시체. 2층 끝에 금빛 상자 |
| 6 | 성당 ⚑ | 실내 (pillars) | 5 | 웨이포인트. 납골당으로 내려가는 계단 |
| 7·8 | 납골당 1·2층 | 던전 | 6·7 | 우두머리 **뼈활 레나** — **퀘스트 3** → 전설 확정 하나 |
| 9 | 도살장 | 보스 방 | 8 | **도살자** — **퀘스트 4** → 2막 열림 |

2막 **안개 숲**(늑대·독거미·버섯 주술사 · 보스 거미 여왕 · Lv 9~16) · 3막 **잠긴 지하도**(방패병·강령술사·산성 토사꾼 · 보스 관리인 · Lv 17~24) · 4막 **심연**(그림자·포격 악마 · 최종 보스 심연의 군주 · Lv 25~30).
(브랜치 `wip/act2-forest` 에 2막 몬스터 4종의 sim 로직과 숲 맵이 보관돼 있다 — D6 에서 쓴다.)

### 5.2 지역 이동

- **출구**(길 끝 · 문 · 계단 · 동굴 입구)에 들어서면 **그 사람만** 이어진 지역의 맞은편 입구로 간다. 파티원은 서로 다른 지역에 있을 수 있다(한 명은 마을에서 장을 보고 셋은 던전에). → 12장 멀티 지역 sim.
- **웨이포인트**: 밟으면 그 캐릭터에게 영구히 열린다(세이브). 웨이포인트에서 F → 열린 곳 목록 → 이동.
- **타운 포털(T)**: 지금 자리와 마을에 푸른 문이 생긴다. 파티원 누구나 드나든다. 새로 열면 옛 문은 닫힌다. 재료 없음(디아블로 3·4 처럼 무한), 시전 2초(맞으면 끊김).
- 지역에 들어서면 화면 위에 **지역 이름 배너**(큰 명조체, 천천히 사라짐) + 지역 레벨.
- 마을은 **안전지대**: 사격·스킬 불가, 몬스터 없음, 체력·자원 가득.

### 5.3 죽음 · 난입 · 방장 끊김

- 쓰러짐 → 동료가 일으킴은 그대로(협동의 핵심). 혼자거나 아무도 못 오면 죽음.
- **죽으면 마을에서 일어난다.** 돌아가는 길은 타운 포털(남아 있으면) 또는 웨이포인트.
  - 없음: 잃는 것 없음. · 소실: 골드 20% · 지금 레벨 경험치 10%. · 하드코어: 그 게임에서 탈락(관전) + **마지막으로 마을에 들어온 뒤 얻은 것을 잃는다** — 하드코어는 마을에 들어설 때만 저장한다.
- 난입한 사람은 방장이 있는 막의 **마을에서** 시작한다.
- 게임의 퀘스트 진행은 **방장 캐릭터의 것**으로 시작한다(디아블로 2). 같은 게임에 있던 사람은 깬 퀘스트를 같이 인정받는다(자기 단계와 맞을 때).

## 7. 전투 — 총은 모으고, 스킬은 쏟는다

- 사격·재장전·정조준·구르기·약점 치명타는 **그대로**(사용자 확정).
- **자원 "집중"**(오른쪽 구슬, 푸른빛): **총이 맞을 때 찬다**(치명타는 더), 스킬이 쓴다. 디아블로의 생성기/소비기 고리를 총 = 생성기로 옮긴 것. 궁극기는 재사용 대기만.
  - 오른쪽 구슬이 탄약에서 집중으로 바뀐다. 탄약은 스킬 바의 무기 칸에 숫자로(재장전 고리 포함).
- 스킬 칸: **Q · E · 1 · 2**(액티브 넷) + **X**(궁극기). 처음에는 Q·E·X 만 있고(기존 셋), 나머지는 스킬 트리에서 연다.
- 몬스터 밀도를 올린다: 무리 크기 1.5배, 약한 졸개(한두 발) 비중↑ — 스킬 한 번에 여럿이 쓰러져야 한다. 대신 개별 피해는 낮춘다. (D4 마일스톤에서 봇 계측으로)
- 기력(달리기)은 남긴다. 구르기는 기력 대신 **충전식 2회**(D4 회피).

## 8. 성장 — 선택이 있는 레벨업

- 레벨업마다 **스킬 포인트 1**(+ 퀘스트 보상 막당 1~2). 만렙 30 + 퀘스트 → 약 36 포인트.
- 캐릭터마다 **스킬 트리**(K): 액티브 5(기존 Q·E + 새 셋, 그중 넷을 칸에 건다) · 궁극기 1 · 패시브 4(기존 특성 포함) = 10개. 스킬마다 최대 5랭크, 3·5랭크에서 **변형 하나를 고른다**(예: 수류탄 → "불바다" 또는 "연쇄 폭발").
- 능력치 직접 분배는 없다(D4). 능력치는 레벨 + 장비.
- 마을에서 골드로 **재분배**.
- 전설 아이템은 **고유 효과** 하나(예: "관통 저격이 벽에 튄다") — 빌드의 나머지 절반.
- 용병(D2): 마을의 용병 대장에게서 동료 봇을 고용한다(지금의 "동료 봇" 을 세계 안으로). 혼자 하기의 봇 수 메뉴는 없앤다.

## 9. 전리품 · 경제

| 나오는 곳 | 내용 |
|---|---|
| 졸개 | 골드 더미 35% · 물약 4% · 아이템 12% (지금 7%) |
| 정예 | 골드 + 아이템 1~2 확정(등급↑) |
| 우두머리 · 보스 | **전리품 분수**: 아이템 3~6 · 골드 더미 여럿 · 물약. 첫 처치는 희귀 이상 확정 |
| 상자 · 금빛 상자 | 아이템 1~3 / 3~5(던전 끝) |
| 항아리 · 통 · 유골 더미 | 쏘거나 F 로 부순다 — 골드·가끔 물약 |
| 제단 | F → 30초 버프(피해 · 방어 · 경험치 · 속도 중 하나) |
| 보물 고블린 | 드물게. 도망치며 골드를 흘린다, 잡으면 분수 |

- **골드·물약·건강 구슬은 밟으면 줍는다. 아이템은 F**(가까운 것부터) — 가방이 차면 못 줍는다. 아이템은 등급 색 이름표로 바닥에 보인다(자기 것 + 버려진 것만).
- **물약**: 키 `3`, 충전식 4개(D4). 최대 체력 35% 를 3초에 걸쳐. 물약 드랍으로 채운다. 상인에게서 상한을 늘린다.
- **상인**: 사고팔기(파는 값 = 아이템 레벨 × 등급), 매일(게임마다) 바뀌는 진열. **대장장이**: 접두 하나 다시 굴리기(D3 마법부여) · 등급 올리기. **도박꾼**: 미확인 아이템. **보관함**: 100칸, 캐릭터 공유.
- 골드가 쓰이는 곳: 상인 · 도박 · 대장장이 · 재분배 · 용병 · 물약 상한. (지금은 0곳)

## 10. 퀘스트 · 이야기

- 막당 퀘스트 4개(5.1 표). 상태는 캐릭터 세이브에(난이도별).
- NPC 위에 **!**(줄 퀘스트) / **?**(완료). F 로 대화 — 초상 + 두세 문단, 글자가 흐른다. 건너뛰기 가능. 음성 없음.
- 퀘스트 기록(J) + 화면 오른쪽 추적(지금의 목표 추적 패널을 퀘스트 추적으로).
- 큰 줄거리: 성당 종이 멈춘 밤 → 숲으로 번진 부패 → 도시 아래의 의식 → 심연. 막 보스를 잡으면 짧은 글 장면. 4막 끝에 엔딩 + 악몽 난이도 열림.

## 12. 기술 구조 — 멀티 지역 sim

파티원이 서로 다른 지역에 있을 수 있어야 한다(5.2). 락스텝은 그대로 두고 **판 안에 지역을 여럿** 둔다.

```ts
interface AreaState {            // 지역 하나의 움직이는 것 전부
  id: number                     // world.ts 의 지역 번호
  monsters; mshots; bullets; globes; zones; throws; drops
  objects                        // 상자·항아리·제단·포털·웨이포인트의 상태
  monstersTotal; lastActive      // 마지막으로 사람이 있던 틱
}
interface GameState {
  players                        // PlayerState.area = 지금 있는 지역
  areas: AreaState[]             // 사람이 있는 지역 + 잠시 보관 중인 지역
  world                          // 게임 전체 깃발: 퀘스트 단계 · 죽은 보스/우두머리 · 열린 포털
  …
}
step(state, maps: (areaId) => GameMap, inputs)
```

- **사람이 있는 지역만** 틱을 돌린다(번호 순 — 결정론). 최대 4개 × 0.12ms.
- 사람이 없는 지역은 얼린다(탄·투사체는 버리고 몬스터·바닥 것은 유지). 얼린 지역은 최근 3개만 두고 나머지는 버린다 → 다시 가면 새로 채워진다(죽은 보스·우두머리·연 상자는 `world` 깃발로 기억).
- 맵은 상태 밖: `maps(areaId)` 가 (게임 시드, 지역 번호)로 만들어 캐시한다. 모든 브라우저가 같은 틱에 같은 맵을 만든다.
- 이벤트에 `area` 를 싣고, 렌더러·소리는 **내 지역 것만** 쓴다. 파티 창에 동료의 지역 이름.
- 해시는 players + 사람이 있는 지역만. 난입·리싱크 스냅샷은 전체(얼린 3개 포함, 상한 약 250KB — Trystero 가 나눠 보낸다).
- 투기장은 지역 하나짜리 판으로 그대로 둔다.
- 세이브(`Sheet`)에 추가: 스킬 포인트 배분 · 난이도별 퀘스트 · 웨이포인트 · 물약 · 용병. 보관함은 캐릭터 밖(계정 칸). 하드코어는 마을에 들어설 때만 저장.

## 15. 개발 규칙 (다시 어긋나지 않게)

1. 만들기 전에 묻는다: **"디아블로에서는 이것이 어디에, 어떻게 있나?"** 답이 이 문서에 없으면 이 문서를 먼저 고치고(사용자 확인) 만든다.
2. **메뉴로 풀지 말고 세계 안에서 푼다.** 지역 고르기 → 웨이포인트, 상점 → NPC, 동료 → 용병 대장, 다음 단계 → 걸어서.
3. 덕에서 온 대전 구조(준비·카운트다운·결과표·다시 하기·점수)는 **투기장 밖에 두지 않는다.**
4. 3장의 사용자 확정 결정은 임의로 바꾸지 않는다. 임의로 정한 것은 CHANGELOG 에 "(임의 결정)" 으로 적고, 2장의 정본 표를 따른다.
5. 마일스톤이 끝날 때마다 14장의 완료 기준으로 자가 점검한 결과를 HANDOVER 에 적고, 이어서 다음 마일스톤으로 간다.
6. 그 밖의 작업 규칙(시험 → 빌드 → 브라우저 확인 → 서버·탭 닫기 → 문서 → 커밋·푸시, 한국어 주석, 결정론 규칙)은 HANDOVER 그대로.
